🏢 INDUSTRY CONTEXT:
-------------------
This is an ENTERPRISE-GRADE AVIATION OPERATIONS PLATFORM designed for:

1. AIRLINES (Commercial Operators)
   - Operations Control Centers (OCC)
   - Crew Scheduling Departments  
   - Station Managers at hubs
   - Director of Operations

2. MROs (Maintenance Repair Overhaul)
   - Maintenance controllers tracking AOG (Aircraft on Ground) events
   - Predictive maintenance based on delay patterns
   - Technical delay root cause analysis

3. GROUND HANDLERS
   - Ground operations managers
   - Turnaround time optimization
   - Delay attribution analysis

🎯 CORE PURPOSE:
----------------
Transform raw flight data into predictive operational intelligence to:

BEFORE: Airlines use Excel + manual delay coding (reactive)
AFTER:  Real-time AI dashboard with predictive alerts (proactive)

💡 BUSINESS VALUE:
------------------
• Problem: A 60-minute delay costs $10,000+ in fuel, crew, and passenger compensation
• Solution: Predict delays 4 hours before departure → Mitigate early
• ROI: $2M+ annual savings for a 50-aircraft fleet

🛠️ TECHNICAL ARCHITECTURE:
---------------------------
LAYER 1: DATA INGESTION
   - Accepts CSV flight operations data
   - Auto-generates 500 realistic demo flights if no data provided
   - Columns: flight_id, tail_number, crew, route, delay_code, etc.

LAYER 2: PROCESSING ENGINE
   - Pandas for data manipulation
   - DateTime filtering (Last 24H, 7D, 30D, All Time)
   - Multi-dimensional filtering (Aircraft + Crew + Route + Status)

LAYER 3: ANALYTICS ENGINE
   - OTP (On-Time Performance) calculation: (On-Time Flights / Total) × 100
   - Delay impact analysis using IATA standard codes
   - Crew performance scoring by individual captain
   - Route health metrics by city-pair

LAYER 4: VISUALIZATION LAYER
   - Plotly for interactive charts (trend lines, pie charts, heatmaps)
   - 6 KPI metric cards (Total Flights, OTP, Delays, etc.)
   - 5 analysis tabs (Delay Analysis, AI Alerts, Crew, Routes, Summary)
   - Dark "cockpit" theme optimized for 24/7 operations centers

LAYER 5: EXPORT LAYER
   - FPDF2 for professional PDF report generation
   - Reports include: Executive summary, delay tables, crew performance
   - One-click export for management briefings

📊 KEY METRICS EXPLAINED:
-------------------------
• OTP (On-Time Performance): Industry standard metric, target >80%
• Critical Delays: >60 minutes (passenger compensation threshold in EU)
• Delay Codes (IATA):
  - Weather: Acts of nature
  - ATC: Air traffic control flow constraints
  - Aircraft Tech: Mechanical issues
  - Crew: Staffing/rest violations
  - Ground Handling: Baggage/catering/fueling
  - Passenger: Security/late boarding
