NEW PROJECT: AerOps AI v2.0 - Aviation Delay Prediction Platform

Airlines lose $25B+ annually to flight delays. Most operations teams still use Excel and react AFTER the cascade has started.

So I built an end-to-end intelligence platform that predicts delays before they happen.

THE PROBLEM
A 60-minute delay doesn't just cost $10K in fuel and crew. Under EU261, it triggers passenger compensation. It cascades through the network. And by the time it's reported, it's too late.

WHAT I BUILT (Full Data Science Pipeline)

1. DATA INGESTION
   - Real US DOT flight data (BTS Transtats - millions of flights)
   - Live aviation weather (METAR/TAF from Aviation Weather Center)
   - FAA airport delay status API
   - 4,553 airports from OurAirports

2. DATABASE + FEATURE ENGINEERING
   - SQLite with indexed schema (flights, weather cache, IATA codes)
   - 18 engineered features: cyclical time encoding, target-encoded airports, historical delay rates
   - Proper IATA AHM 730 delay codes (66 real codes, not made-up categories)

3. ML PREDICTION MODEL
   - GradientBoosting classifier + regressor
   - 77% accuracy, 0.70 AUC-ROC on held-out test set
   - Temporal train/test split (no data leakage)
   - Top feature: route historical delay rate (29% importance)

4. INTERACTIVE DASHBOARD (6 tabs)
   - Delay analysis with IATA code distribution
   - ML prediction: pick a route, get delay probability
   - Live ops center with METAR weather cards
   - Root cause analytics with responsibility attribution
   - Airline & fleet performance leaderboards
   - Route analytics with distance vs delay correlation

5. PRODUCTION ENGINEERING
   - Modular architecture (15+ Python modules)
   - 19 automated tests (pytest)
   - CLI scripts for reproducible workflows
   - PDF export for stakeholders

TECH STACK
Python | Streamlit | Plotly | scikit-learn | SQLite | Pandas | METAR API | BTS Data

WHY THIS MATTERS
